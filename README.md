# Start Your Day - Firefox Container Launcher Extension

A Firefox extension to open a configured list of URLs in specific Firefox Containers with a single click.

## Overview

This extension uses native Firefox Contextual Identities (Containers) to assign URLs to specific container profiles.

## How to Use

1. Left-click the extension icon in the Firefox toolbar to open all your active URLs in their assigned containers.

## How to Configure

1. Right-click the extension icon in the toolbar (or right-click anywhere on a web page) and select **Configure Container URLs & Settings**.
2. Add your URLs and select the target Firefox Container from the dropdown list (or select "Default (No Container)").
3. Click **Save Settings**.
